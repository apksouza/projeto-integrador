# Projeto Integrador - Sistema de Controle de Estoque

## Faculdade Gran

Projeto desenvolvido para a disciplina Projeto Integrador.

## Tecnologias utilizadas

### Backend
- Node.js
- Express
- SQLite

### Frontend
- React.js
- Axios

## Funcionalidades

- Cadastro de produtos
- Cadastro de fornecedores
- Associação entre produtos e fornecedores
- CRUD completo

## Estrutura

/backend
API REST responsável pelas regras de negócio.

 /frontend
Interface do usuário desenvolvida em React.
